# Counter v1.0.1 — Global Hotkeys and the System Tray

The first thing I noticed when trying to use Counter was that the keyboard shortcuts only worked when the Counter window had focus. That kind of defeats the purpose when you are trying to keep track of interruptions while working in another program.

So this update fixes that.

## What changed

| Shortcut | Action |
| --- | --- |
| Ctrl+Alt+1 | Count +1 |
| Ctrl+Alt+2 | Creap +1 |
| Ctrl+Alt+Z | Undo last manual entry |

These are Windows-wide shortcuts, as long as Counter is running. The old Ctrl+1, Ctrl+2, and Ctrl+Z shortcuts still work inside the app window.

I also added an optional **system tray icon**. You can hide the window, keep recording events, then right-click the icon to reopen Counter, add a Count or Creap, undo, or exit completely. The hotkey and tray options are saved between launches.

## Getting started

1. Download and run the updated \`Counter.exe\`.
2. Leave global hotkeys and the system tray enabled if you want to use both.
3. Close the window to hide the application rather than exiting.
4. Use the tray menu's **Exit Counter** option when you really want to stop it.

If you are running from source, install the optional tray dependencies:

\`\`\`powershell
python -m pip install -r requirements-gui.txt
\`\`\`

## A couple of things to know

Global hotkeys use Windows \`RegisterHotKey\`, not a keyboard-capture hook. Only those three combinations are registered. If another application is already using one, Counter reports the conflict.

The database and existing counts are unchanged. The tray and global hotkeys are Windows-only; the rest of Counter still runs from Python on other platforms.

The automated tests and Windows packaging check passed for this release. Actual desktop hotkey and tray interaction still need to be checked on Windows. The executable is unsigned, so SmartScreen may show its usual warning.
