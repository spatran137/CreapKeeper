# Counter v1.0.1 — Global Hotkeys & Tray Support

Counter can now stay out of your way while you work: log **Count** (direct walk-up) and **Creap** (silent approach) without switching to the Counter window.

## Added
- **Ctrl+Alt+1** — Count (+1) from anywhere in Windows.
- **Ctrl+Alt+2** — Creap (+1) from anywhere in Windows.
- **Ctrl+Alt+Z** — Undo last manual event.
- Optional **system tray icon** with Show, Count, Creap, Undo, and Exit commands.
- **Close-to-tray mode**: closing the window hides it while the hotkeys stay active.
- Two persistent switches for global hotkeys and tray mode in the GUI.

## Compatibility and safeguards
- Keeps Ctrl+1 / Ctrl+2 / Ctrl+Z as window-only alternatives.
- Keeps the v1.0.0 SQLite schema and all stored counts; no database migration required.
- Hotkeys use Windows RegisterHotKey, **not** a keyboard monitoring hook.
- Only three specific key combinations are registered; other typing is not captured.
- A conflicting hotkey is reported rather than silently failing.
- Both background features are Windows-only; the Python GUI and CLI remain cross-platform.
- The tray icon and global shortcuts work **only while Counter is running**.
- The Windows executable includes its desktop dependencies. No Python installation is necessary.

## How to use
1. Download and run **Counter.exe** from the assets below.
2. Leave the **Global hotkeys** option checked.
3. To keep Counter running without an open window, leave **System tray** enabled and close the window.
4. Right-click Counter's notification-area icon and choose **Exit Counter** to quit fully.

When running from source, install the optional tray packages with:
 
    python -m pip install -r requirements-gui.txt

If hotkeys do not register, another app may be using the combination; turn off the conflicting program's binding and re-enable the Counter hotkeys.

**Note:** The executable is unsigned and Windows may show an unfamiliar-app warning. This release has automated CLI/storage/settings tests and a Windows packaging check; real desktop hotkey/tray behavior should also be verified on a local Windows desktop.
