# CreapKeeper v1.2.0 — The Project Formerly Known as Counter

Back in 2017, two kinds of desk interruptions inspired a tiny counter. It now has hotkeys, a system tray, SQLite, a firewall assistant, and a LAN scoreboard. Apparently the joke required a proper brand.

## What's new
- **CreapKeeper** is the new application name and portable Windows executable: `CreapKeeper.exe`.
- The LAN scoreboard is now **The Creap Report**. Same cumulative Count and Creap lines; same offline, read-only LAN setup on port 8765.
- Updated application title, tray menus, error messages, CLI branding, README and build workflow.
- New Python launcher `python Counter/CreapKeeper.py` (old `Counter/Counter.py`, `count.py`, and `creap.py` entry points still work).
- Additional branding and backwards-compatibility checks.

## Upgrading from Counter v1.1.1
1. Exit the old `Counter.exe` **fully** using its tray Exit menu.
2. Download and launch **CreapKeeper.exe**.
3. Your existing counts and preferences remain available automatically—**no reimport, database migration or folder rename**.
4. If the LAN dashboard does not open on another PC, select **Check firewall**. A rule limited to the old `Counter.exe` path might need updating, but port-based TCP 8765 rules should still apply.

## Preserved on purpose
- The **Count** and **Creap** buttons and the original *inside-joke spelling*.
- Database and settings path, including `%LOCALAPPDATA%\Counter\Counter.db`.
- Existing `COUNTER_DB_PATH` environment override and SQLite event schema.
- Stable firewall rule internal identifier `Counter-LAN-Dashboard-8765` (new friendly display name: **CreapKeeper LAN Dashboard**).
- Privacy behavior: manual events only, opt-in LAN view, no external network service.

Automated checks run on Windows/Linux and the Windows executable is built by GitHub Actions. Test global hotkeys, tray behavior and LAN access on your Windows desktop after upgrading.
