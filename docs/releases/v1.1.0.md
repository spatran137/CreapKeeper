# Counter v1.1.0 — LAN Dashboard

The legendary **Count** and **Creap** totals can now be viewed by teammates using a **simple local-network website**!

## Added

- One-page dashboard showing separate blue **Count** and orange **Creap** cumulative trend lines.
- Overall totals and the last 30 days of daily cumulative values.
- Auto-refresh every 30 seconds, including while Counter is hidden in the system tray.
- An opt-in **Share read-only chart on local LAN** checkbox.
- **Open dashboard** and **Copy LAN link** buttons.
- Built-in Python HTTP server on TCP **8765** — no NGINX, Docker, external website, cloud service, or separate database.
- No external JavaScript libraries or resources required; works on disconnected LANs.
- Tests for HTTP routing, aggregation, allowed LAN clients, and lifecycle management.

## How to view

1. Download and launch the new `Counter.exe` on the Windows machine keeping score.
2. Enable **Share read-only chart on local LAN (HTTP port 8765)**.
3. On another PC on the same LAN, visit `http://COUNTER-PC:8765/` using the hostname shown in Counter, or replace the name with that PC's private IPv4 address.
4. If Windows Firewall blocks access, permit incoming port 8765 **only on the Private/Domain LAN**, ideally restricted to `LocalSubnet` and `Counter.exe`. No public access or port forwarding is needed.

## Privacy and compatibility

The service is disabled by default and is **read-only**. It publishes aggregate totals and daily lines, not the raw event log or the SQLite file. Clients with public IPv4 or IPv6 addresses are rejected; this is not a substitute for network firewall rules, and the dashboard does not use authentication.

Current hotkeys, system tray behavior, SQLite data and import/export features are unchanged. Keeping Counter running in the tray also keeps the dashboard running. Exit Counter or turn off sharing to shut it down.

**Validation:** Automated tests run on Linux and Windows, plus Windows EXE packaging. Final LAN/firewall access needs a real Windows PC check.
