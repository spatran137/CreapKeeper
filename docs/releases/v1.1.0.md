# Counter v1.1.0 — A Small LAN Dashboard

After getting the desktop app working, I wanted to see if I could share the running counts with one or two other people. Not enough traffic to justify another server or anything complicated. Just a page with a couple of lines on a graph.

This version adds that page.

## The dashboard

- A blue line for **Count** and an orange line for **Creap**.
- Daily cumulative values for the most recent 30 days and overall totals.
- Automatic refresh every 30 seconds.
- A built-in HTTP server on **TCP 8765**.
- A single self-contained chart page: no external libraries, CDN, internet connection, Docker, or NGINX required.
- **Open dashboard** and **Copy LAN link** buttons.

## How I use it

1. Start \`Counter.exe\` on the computer recording the events.
2. Enable **Share read-only chart on local LAN (HTTP port 8765)**.
3. Open the displayed link on another LAN computer, or use \`http://COUNTER-PC-IP:8765/\`.
4. Leave Counter running in the tray if you want the page to stay online.

If the page works on the Counter PC but not anywhere else, start with Windows Firewall. TCP 8765 needs an inbound rule for the trusted Private/Domain network, preferably limited to \`LocalSubnet\`. There is no need for router port forwarding.

## What stays private

LAN sharing is **off by default**. Viewers see only totals and the graph, not the SQLite file or individual records. The page is read-only and does not have authentication, so anyone with allowed network access can see those totals. The server rejects public-client IP ranges, but you should still restrict access with your firewall.

The old hotkeys, tray, database, and import/export features are unchanged. Automated tests cover routing, aggregation, and server lifecycle; access from another Windows computer still needs a real LAN test.

Honestly, this was more interesting to build than the two-button app needed to be. That is part of why I am keeping the project going.
