# CreapKeeper v1.3.0 — Even the Creeping Gets Updates

We have officially given an office interruption counter a software update system. This was surely on the 2017 roadmap.

## New: GitHub-powered updates
- Automatic check for new stable GitHub releases (at most daily on the packaged Windows app), with an option to disable it.
- **Check for updates** in the desktop window and system tray.
- Consent-based download, SHA-256 digest + size verification, safe staging, replacement after the app exits, and restart.
- Previous executable backed up as `CreapKeeper.exe.previous` if a rollback is needed.
- No token, extra server, update service or outbound sharing of your counts.
- Gracefully handles offline desktops, unavailable releases, verification failures, and unwritable installation directories.

## Compatibility
- All existing Count and **Creap** events stay in the same SQLite database.
- LAN dashboard and firewall settings remain in place, including the intentionally misspelled event name.
- **Updating from v1.2.0 requires downloading v1.3.0 manually once.** Subsequent releases can be installed using the built-in updater.
- Automatic installation requires a packaged Windows executable in a writable directory; source checkouts can link to the latest release instead.

## Verification
Automated tests check release-version comparisons, asset URL validation, digest enforcement, download size, preferences and platform guards. The Windows one-file executable is built by GitHub Actions. **The detached PowerShell replacement/restart flow still requires a manual smoke test on an actual Windows desktop** before treating unattended updates as fully validated.
