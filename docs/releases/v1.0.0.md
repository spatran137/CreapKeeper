# Counter v1.0.0 — Bringing an Old Project Back

This started as a small office joke back in December 2017. We had two ways of recording someone coming up to a desk: a normal **Count**, and a surprise **Creap**. And yes, Creap is spelled that way on purpose.

For this first proper release, I wanted to see if I could take the original idea and turn it into a working Python 3 application without losing the old history.

## What I added

- A Python 3 desktop interface for **Count** and **Creap**, with running totals and recent history.
- **Undo last click**, **Export CSV**, and window-focused shortcuts: Ctrl+1, Ctrl+2, and Ctrl+Z.
- SQLite storage, created automatically in a per-user data directory.
- Command-line entry points if you would rather use a terminal.
- An importer for the original 2017 \`Counter.db\`.
- Automated Windows/Linux tests.

## Getting started

Windows users can download and run the portable **Counter.exe** attached to this release. Python is not required for that executable.

If you want to run it from source, install Python 3.10 or newer and run:

\`\`\`powershell
python Counter/Counter.py
\`\`\`

Linux may also need the \`python3-tk\` package for the GUI.

## Moving over the original history

The database format changed, so make a backup of the old \`Counter.db\` before importing. Use **Import old DB** in the app, or:

\`\`\`powershell
python Counter/cli.py import-legacy "C:\path\to\Counter.db"
\`\`\`

The original file is left alone. Importing the same source path twice skips previously imported records.

## Final thoughts

The Windows executable is unsigned and SmartScreen may show a warning. Everything stays local in this version: no LAN page and no monitoring. It is still just a manual counter, which is exactly where I wanted to start.
