# Counter v1.0.0 — The Office Encounter Tracker

The first official release of Counter, originally created in December 2017 to tally two very different kinds of desk interruptions.

## What's new
- **Count:** Record a direct walk-up interruption.
- **Creap:** Record the silent, stand-behind-you approach (the original spelling stays!).
- Rebuilt **Python 3** desktop GUI with running totals and recent history.
- **Undo last click**, **CSV export**, and **keyboard shortcuts** (Ctrl+1, Ctrl+2, Ctrl+Z).
- SQLite database that initializes itself in a per-user data folder.
- A command-line version for shortcuts and automation.
- Import an original 2017 `Counter.db` using **Import old DB** in the GUI or `python Counter/cli.py import-legacy PATH`.
- Documented setup and database migration, plus Windows/Linux automated tests.

## Downloads
- **Counter.exe** — Portable Windows GUI application. Download it below and run it directly; Python is not required.
- **Source code (zip / tar.gz)** — Python 3.10+ application, CLI scripts, and tests. To start the GUI from source, run `python Counter/Counter.py`. Linux may require the `python3-tk` OS package.

## Upgrading from the 2017 version
The database format changed. **Back up your original `Counter.db`** and import it through the desktop app's **Import old DB** button or the command-line importer. The original file is not modified. Reimporting the same source file path skips already imported records.

## Notes
The Windows executable is unsigned; Windows SmartScreen may display a warning for an unfamiliar program. Event data is stored **locally** and no tracking or network features are included.

This is a lighthearted manual counter, not a people-monitoring tool.
